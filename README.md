# Corevexal Foundation

Create a completely new, premium, production-ready website for my company:

COREVEXAL

IMPORTANT:

This is NOT a redesign of an existing technology-company website.

Create a completely new website architecture, new information hierarchy, new homepage, new navigation, new content structure, and new service positioning.

The previous version was too heavily focused on software engineering.

The new Corevexal website must primarily focus on:

1. BUSINESS FORMATION

2. BUSINESS BANKING & FINANCIAL ACCOUNT SETUP CONSULTING

3. PAYMENT PLATFORM SETUP & BUSINESS PAYMENT SOLUTIONS

4. DIGITAL / TECHNOLOGY SERVICES

Technology and software services should remain available as a secondary category that can be expanded later.

The website must be designed so that Corevexal can add many more services in the future without redesigning the entire website.
